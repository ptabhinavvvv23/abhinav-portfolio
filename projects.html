AgroSathi - Smart Farming Assistant

AgroSathi is an AI-powered green farming assistant mobile application designed to support farmers with smart decision-making. It provides weather-based crop recommendations, soil and irrigation guidance, pest and disease solutions, and a mentorship system where farmers can learn from experts.

The platform includes features like live queries, farmer–mentor interaction, crop insights, and an admin panel for monitoring and verification. Built using Flutter and Firebase, AgroSathi focuses on sustainable agriculture and improving farming efficiency using technology.
